# 🛒 Sharma Kirana — Grocery Store Website (HTML CSS JS)

Ek complete chhoti **kirana / grocery store website** — sirf HTML, CSS aur JavaScript se. Tech Bro Z ke 8 AM Short mein ise live banaya aur redesign kiya 🔥

🌐 **Live demo:** https://nm621532-byte.github.io/kirana-store-website-techbroz/

## Isme kya hai
- Saman ki list (Atta, Chawal, Chai Patti, Maggi) — JavaScript `map()` se har item ka card
- **Add** button dabao → cart ka total (₹) badhta hai
- Green header, cream background, rounded cards with shadow
- 2-column grid + orange buttons
- 🚚 Free Home Delivery offer banner

## Khud chalao
1. Repo download karo (Code → Download ZIP) ya `git clone https://github.com/nm621532-byte/kirana-store-website-techbroz.git`
2. `index.html` browser mein kholo — bas! Koi install nahi.
3. Naya saman add karna hai? `script.js` mein `items` list mein ek line jodo: `["Sugar 1kg", 48, "🍬"],`

💻 Free online editor: https://techbroz-code.sites.tab.bot/ (wahan "🌐 Website live karo" dabao aur apni site online karo)
